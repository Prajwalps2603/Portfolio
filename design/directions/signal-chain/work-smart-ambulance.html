PMP-ACQ-02 / Full-stack IoT prototype

Smart Ambulance Traffic Clearance

From an ambulance's GPS to a traffic light: mobile app, realtime backend, message broker and ESP32 firmware, built as one system.

Layers CH1 / CH2 / EXT / OUT Stack Flutter / Node + Express / MQTT / Socket.IO / ESP32 / Docker License MIT

1Features

Features

  • Ambulance mission orchestration: start, live updates, completion
  • Real-time lane-clearance alerts to roadside smart poles over MQTT
  • Traffic-light pre-emption along the ambulance route
  • Control center via logs and Socket.IO events
  • Flutter app to start a mission and stream live GPS location
  • Naive ETA from distance and speed; Google Directions optional

2Description

Description

The Flutter app starts a mission with a destination hospital and streams the ambulance's position to a Node.js / Express backend. The backend manages missions, computes an ETA, and publishes two kinds of MQTT messages through an Eclipse Mosquitto broker: lane-clearance alerts for smart poles, and phase commands for traffic lights.

ESP32 boards (Arduino framework) subscribe to those topics: a smart pole plays audio and shows an LED direction, a traffic light switches its LED or relay states to an ambulance pre-emption phase. A control center follows every mission in real time over Socket.IO. Broker and backend run together in Docker.

6Application notes

Known limits, stated plainly

  • This is a prototype. A real deployment needs secure auth (JWT / mTLS), intersection detection, precise geofencing and integration with traffic controllers.
  • Broadcast topics (alerts/all, traffic/all/command) would become per-pole and per-intersection topics in a production design.
