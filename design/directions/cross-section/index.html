Drone Intelligence System

AI knowledge platform
India's drone rules (DGCA)

Surface: what users do

Ask India's drone rules in plain language, check compliance, work out flight time and ROI.

  1. AskAI chat over DGCA rules, answered with sources
  2. Checkwhether a flight is compliant with DGCA rules
  3. Estimateflight time and range from battery, weight and weather
  4. CalculateROI for drone operations, with break-even
  5. Watchlive KPIs on the dashboard (simulated mission data)
React 19FastAPIChromaDBGeminiWebSocketsMCPDocker Repository ↗(opens in a new tab)

Section: how it is wired

Drawn from the repository [1]

Flow: a chat question goes from the React 19 dashboard to FastAPI over HTTP. FastAPI queries ChromaDB, which returns the top 5 matching chunks. Gemini 2.0 Flash writes the answer with its sources, which travels back to the dashboard. Live KPIs are pushed over a WebSocket. A separate MCP server gives Claude Desktop the same tools. Everything runs under Docker Compose.

Interface

React 19 dashboardchat · calculators · regulations · live KPIs

The dashboard asks over HTTP and listens on a WebSocket, which pushes KPIs every few seconds (simulated mission data).

API + logic

FastAPI/api/chat · /check/compliance · /calculate/*
MCP serverstdio → Claude Desktop

REST routes for chat, DGCA compliance, flight time and ROI. The MCP server exposes four tools to Claude Desktop. [1]

Data

ChromaDB74 chunks · all-MiniLM-L6-v2

Local all-MiniLM-L6-v2 embeddings over 74 indexed chunks; each question retrieves the top 5. [1]

Intelligence

Gemini 2.0 FlashRAG answer + sources
Fallbackcontext-only answer

Gemini writes the answer and cites its sources. If it fails, the answer is built from the retrieved context alone. [1]

Delivery

The API and the Nginx-served frontend ship as two containers. [1]
